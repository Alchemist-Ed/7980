#Overview of iMAML in cold start problem

This research explores the usage of implicit gradients algorithm combined with other techniques in preferen-adaptive meta learning model to solve cold start problem in recommendation system. Although the PAML model achieved strong performance in cold start datasets, it is noticeable that this model requires a significant amount of training time and resources. To address this issue and enhance the model efficiency, a research on studying different algorithms to save training time is conducted. The main objective of the research is to find ways to enhance model efficiency while maintaining and potentially improving model accuracy.
In the set up stage, data was collected from yelp datasets which was used in the PAML paper. Then data had been cleaned and transformed to fit into an enhanced iMAML model where implicit gradient algorithm was added and residual block structure was also added to replace original neural network layers. In addition, changes were also made in user data embedding as a multi-head attention mechanism was added to replace single-head attention mechanism. Moreover, rounds of hyper parameters fine-tuning were conducted.
During evaluation, the iMAML model was splitted into two models where one has all the add-ons features to keep model complexity and the other contains only the implicit gradient structure to keep model simplicity. Both models were also compared to the original model under the same training parameters and training environment and the evaluation process was conducted on yelp datasets. The result showed a significant efficiency improvement for the iMAML model as it saved more than 58% of training time from the original PAML model. Meanwhile, the iMAML models, despite their complexity, showed better stability on NDCG@5 over the PAML model.These findings suggest a way to improve model efficiency in meta-learning models through the usage of implicit gradient algorithm while maintaining models’ accuracy. Moreover, it is a positive sign for further studies of combining implicit gradient algorithm with other cutting edge meta learning models
